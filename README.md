# GESTA — Sistema de Gestión para Comercios

## Descripción del proyecto

GESTA es un proyecto de software orientado a facilitar la gestión de pequeños y medianos comercios, como supermercados, kioscos y pet shops.

La propuesta busca centralizar y organizar información relacionada con productos, stock, ventas, cobros, proveedores y movimientos del negocio, contribuyendo a mejorar el control de las operaciones comerciales.

## Objetivo

Desarrollar una solución de gestión accesible y organizada que permita administrar la información operativa de los comercios y facilitar la consulta de sus registros.

## Alcance del proyecto

El proyecto contempla el análisis y diseño de procesos organizacionales, la planificación del desarrollo del software, el modelado de datos y la documentación técnica de sus funcionalidades.
